DECISÕES FIXADAS
----------------
- Transpilador em Python 3 (só biblioteca padrão). Linguagem destino: C.
- Relatório em Word (.docx), gerado por script Node (docs/fonte/gerar_relatorio.js).
- Escopo: núcleo + extras simples.
    Na gramática: ENTRAR_NA_JAULA/SAIR_DA_JAULA, gato, carneirinho(int), camaleao(double),
    cobra(string), vagalume(bool), fossil(const), vivo/morto, rugir, capturar,
    se_tem_bicho / Se_for_outro_bixo / nao_tem_bicho, contar_carneirinho(while),
    migrar(for), fugir(break).
    Só reservadas (o lexer reconhece, o parser deve rejeitar): alcateia, habitat, zebra,
    se_der_zebra, abater, bicho_solto, CHEGOU_O_ZELADOR, hakuna_matata.
- Comandos SEM ';' (quebra de linha = espaço). ';' só no cabeçalho de migrar( ; ; ).
- Blocos com { }. Comentários ~ ... ~ (podem ocupar várias linhas).
- rugir(expr) quebra a linha automaticamente. Concatenação com + e cobra só dentro de rugir.
- Palavras-chave diferenciam maiúsculas (Se_for_outro_bixo mantido como o grupo escreveu).
- Parar no primeiro erro em todas as fases; saída com código 1.
- Pendentes de confirmação pelo grupo: rugir com quebra automática; camaleao -> double;
  bicho_solto = null (NADA descartado); cidade na capa do relatório.
